# Additional features that strengthen the core

These are recommendations, not extra owner-approved commitments. Priority is based on contribution to expressive possessions, learning, repeat play, or personal style. Relative effort is an estimate and excludes unexpected integration problems.

## What highlight sharing should mean initially

Begin with an intentional user recording or a clearly signaled supported capture flow. Do not promise automatic recording of a moment that occurred before capture started. A rolling replay system needs recorded state or buffered frames, storage limits, and performance testing. Re-simulating touch inputs is not automatically deterministic across versions and devices.

The initial export should be a short portrait clip with an optional small game identity mark and the player's selected name/outfit. No external social account integration is needed to use the system share sheet. Music rights must permit capture/export. No automated posting is authorized by this feature concept.

## Avoid unnecessary early systems

Do not introduce a free-roaming city, housing decoration economy, training attendance calendar, hunger/sleep meters, real-money trading, user-generated asset marketplace, full team-management simulator, or live global multiplayer merely because each is technically imaginable. Each adds ongoing design, moderation, testing, or operations responsibilities.

The mansion is a rewarding practice setting before it is a house simulator. Teammates are useful pass targets and upgradeable players before they are a relationship-management game. Schools establish career identity before they require a forty-stop travel system.

## AI feasibility classification

Most proposed UI, challenge, wardrobe, and local feedback features are plausible with conventional engines and AI-assisted work today, subject to implementation verification. Perfect sport motion, reliable high refresh, robust paid balances, and polished replay export still need specialist judgment and testing. No feature is classified as solved merely because code or an image can be generated.

Choose additions by evidence: does it improve learning, retry rate, player expression, or voluntary sharing? If it only increases the number of screens, content obligations, or currencies, defer it.
